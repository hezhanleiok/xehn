## 已知限制（非缺陷）

1. **WARP 无出口的 DNS 检测** 会报"不一致"：出口与解析器都在 Cloudflare 网内，
   只是 anycast 地理标注不同。假泄露，无法消除。
2. **同一系统开两个代理客户端** 时，`系统代理已被其它程序改动` 会反复出现。
   这是检测在工作，不是故障。
3. **Psiphon / OpenVPN 出口的长时间稳定性** 依赖外部中继，无法保证。
4. **mihomo 版本** 固定 1.19.33；FlClash 用 1.19.34，差异未逐项验证。
